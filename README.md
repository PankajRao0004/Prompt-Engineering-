# Prompt Engineering Experiments

This repository contains my prompt-engineering assignment report and the supporting Gemini API reproduction log.

## Files

- `Prompt_Engineering_Report.md` — full report covering zero-shot vs. few-shot prompting, step-by-step reasoning, structured JSON output, results, analysis, and limitations.
- `api_results/gemini_api_results_20261109_135953.md` — actual prompts and raw responses from seven independent Gemini API requests.

## Models used

- Google AI Studio experiments: Gemini 3.8 Flash.
- Successful API reproduction: Gemini 3.5 Flash-Lite. The model was changed after the Gemini 3.8 Flash API request returned HTTP 503 due to high demand. The report keeps these results separate.

No API key or `.env` file is included in this repository.
